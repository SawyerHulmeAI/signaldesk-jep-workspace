# Workroom

Workroom is a shared collaboration workspace for running a joint execution plan and keeping mutual resources in one place. It replaces the typical spreadsheet-based JEP with a cleaner web experience for both internal teams and customer teams.

## What It Includes

- A `Joint Execution Plan` workspace for success criteria, validation steps, next actions, blockers, shared notes, and visuals
- A `Resource Center` for links, recordings, files, PDFs, contracts, and shared references
- A visual org chart with separate views for shared, internal, and customer team mapping
- Local autosave plus JSON import/export

## Why It Exists

Traditional JEPs often live across spreadsheets, docs, links, and email threads. That makes it harder for both sides to stay aligned on owners, proof points, risks, and the current state of the motion.

Workroom puts the plan and the shared context in one place so both teams can work from the same source of truth.
